Sigortacılık sektörü için geliştirilen,yapay zeka destekli içerik üretimini ve yönetimini merkeze alan bir ASP.NET Core 8 MVC tabanlı web uygulamasıdır.

## 🧩 Kullanılan Yapay Zeka Servisleri
- OpenAI
- Google Gemini
- Anthropic Claude
- Hugging Face
- Tavily AI
- ElevenLabs
